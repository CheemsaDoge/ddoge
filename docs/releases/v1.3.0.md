# DDoge v1.3.0

DDoge v1.3.0 adds Android in-app updates backed by GitHub Releases.

## Highlights

- Added "检查更新" in Settings -> About on Android.
- Checks the latest non-draft, non-prerelease GitHub Release in `CheemsaDoge/ddoge`.
- Detects newer semantic versions and build-number-only updates when release tags include build metadata.
- Shows release notes before downloading.
- Downloads the APK with progress and launches the Android system installer through a FileProvider.
- Handles Android's install-from-this-app permission flow and resumes the pending download after returning from system settings.
- Reworked repository docs: English `README.md`, Chinese `README_Zh.md`, version plan, handoff, and AI review log.

## Notes

- This release must be published as a normal GitHub Release, not a prerelease, because the app uses GitHub's latest-release endpoint.
- Android will still ask the user to confirm unknown-app installation permissions and the final system installer prompt.
